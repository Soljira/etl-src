Getting Started

No separate server required

The REST API runs on the same host and port as this dashboard. If you can see this page, the API is already live at .

1
Check it's healthy
curl /api/v1/health
2
List all datasets
curl /api/v1/datasets
3
Query observations with filters
curl "/api/v1/observations?category=Labor_and_Employment&year=2022"
No authentication required CORS enabled All responses are JSON (UTF-8) Base path: /api/v1

Health Check

GET /api/v1/health Database connectivity check
Request
curl /api/v1/health
200 — healthy
{ "status": "healthy", "database": "connected" }
503 — database unreachable
{ "status": "unhealthy", "database": "disconnected" }

Datasets

GET /api/v1/datasets All datasets with row counts
Request
curl /api/v1/datasets
Response (200)
{ "count": 3, "data": [ { "dataset_id": "Employment_Rate_Annual", "category": "Labor_and_Employment", "row_count": 1248 } ] }
GET /api/v1/datasets/{dataset_id} Metadata for one dataset
ParamTypeDescription
dataset_idstringUnique dataset identifier
Request
curl /api/v1/datasets/Employment_Rate_Annual
Response (200)
{ "data": { "dataset_id": "Employment_Rate_Annual", "category": "Labor_and_Employment", "row_count": 1248, "variables": ["Value"], "year_min": 2000, "year_max": 2023 } }

Categories

GET /api/v1/categories All categories with counts
Request
curl /api/v1/categories
Response (200)
{ "count": 5, "data": [ { "category": "Labor_and_Employment", "dataset_count": 4, "total_rows": 9810 } ] }

Observations

GET /api/v1/observations Query rows — filter & paginate
ParameterTypeDefaultDescription
categorystring—Exact category match
dataset_idstring—Exact dataset ID match
entity_namestring—Partial match (case-insensitive)
variable_namestring—Partial match (case-insensitive)
yearinteger—Exact year
pageinteger1Page number
per_pageinteger50Rows per page (max 500)
Example — no filter
curl "/api/v1/observations"
Example — filter by category and year
curl "/api/v1/observations?category=Labor_and_Employment&year=2022&per_page=100"
Response (200)
{ "data": [ { "id": 1, "dataset_id": "Employment_Rate_Annual", "category": "Labor_and_Employment", "entity_name": "PHILIPPINES", "variable_name": "Value", "year": 2022, "period": "Q1", "value": 95.3 } ], "pagination": { "page": 1, "per_page": 50, "total": 1248, "pages": 25 } }

File Downloads

Download the raw scraped files or cleaned processed CSVs. All endpoints are served from this same host — no extra setup required.

GET /api/v1/files/{kind} List available files (JSON)
ParamValuesDescription
kindraw | processedWhich data folder to list
Request
curl "/api/v1/files/raw"
Response (200)
{ "zip_url": "/api/v1/download/raw.zip", "count": 256, "files": [ { "name": "psa/Employment_Rate.csv", "url": "/api/v1/download/raw/psa/Employment_Rate.csv" } ] }
GET /api/v1/download/{kind}.zip Download all files as ZIP
Raw files ZIP
curl -O "/api/v1/download/raw.zip"
Processed files ZIP
curl -O "/api/v1/download/processed.zip"
GET /api/v1/download/{kind}/{filepath} Download a single file
Request
curl -O "/api/v1/download/raw/psa/Employment_Rate.csv"

Error Responses

All errors return JSON with an "error" key.

StatusMeaningExample body
400Bad request{"error": "kind must be 'raw' or 'processed'"}
404Not found{"error": "Dataset 'XYZ' not found."}
503DB unavailable{"status": "unhealthy", "database": "disconnected"}
