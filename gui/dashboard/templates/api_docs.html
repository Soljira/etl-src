Getting Started

1
Start the Flask API server

The REST API runs on a separate server from this dashboard (port 5000 by default). In the project root:

python main.py

Or via Docker Compose: docker compose up web

2
Confirm it's running
curl http://localhost:5000/api/v1/health

You should get {"status":"healthy","database":"connected"}

3
Make your first real request
curl http://localhost:5000/api/v1/datasets
No authentication required CORS enabled — call from any browser All responses are JSON (UTF-8) Base path: /api/v1

Health Check

GET /api/v1/health Database connectivity check
Example request
curl http://localhost:5000/api/v1/health
Response (200 — healthy)
{ "status": "healthy", "database": "connected" }
Response (503 — unhealthy)
{ "status": "unhealthy", "database": "disconnected" }

Datasets

GET /api/v1/datasets List all datasets with row counts
Example request
curl http://localhost:5000/api/v1/datasets
Response (200)
{ "count": 3, "data": [ { "dataset_id": "DS001", "category": "Labor_and_Employment", "row_count": 1248 } ] }
GET /api/v1/datasets/{dataset_id} Metadata for one dataset
Path parameters
ParameterTypeDescription
dataset_idstringUnique dataset identifier (e.g. Employment_Rate_Annual)
Example request
curl http://localhost:5000/api/v1/datasets/Employment_Rate_Annual
Response (200)
{ "data": { "dataset_id": "Employment_Rate_Annual", "category": "Labor_and_Employment", "row_count": 1248, "variables": ["Value"], "year_min": 2000, "year_max": 2023 } }

Categories

GET /api/v1/categories List all categories with dataset counts
Example request
curl http://localhost:5000/api/v1/categories
Response (200)
{ "count": 5, "data": [ { "category": "Labor_and_Employment", "dataset_count": 4, "total_rows": 9810 } ] }

Observations

GET /api/v1/observations Query rows with filtering & pagination
Query parameters
ParameterTypeDefaultDescription
categorystring—Filter by category name (exact match)
dataset_idstring—Filter by dataset identifier
entity_namestring—Partial match on entity name
variable_namestring—Partial match on variable name
yearinteger—Filter by exact year
pageinteger1Page number (1-indexed)
per_pageinteger50Rows per page (max 500)
Example — all observations, page 1
curl "http://localhost:5000/api/v1/observations"
Example — filter by category and year
curl "http://localhost:5000/api/v1/observations?category=Labor_and_Employment&year=2022&per_page=100"
Response (200)
{ "data": [ { "id": 1, "dataset_id": "Employment_Rate_Annual", "category": "Labor_and_Employment", "entity_name": "PHILIPPINES", "variable_name":"Value", "year": 2022, "period": "Q1", "value": 95.3 } ], "pagination": { "page": 1, "per_page": 50, "total": 1248, "pages": 25 } }

File Downloads

These endpoints are served directly by this dashboard (same host/port — no separate Flask server needed). Use them to download the raw scraped files or the cleaned, processed CSVs.

GET /download/{kind}/ List available files
Path parameters
ParameterValuesDescription
kindraw | processedWhich data folder to list
Example — list raw files
curl "http://localhost:8000/download/raw/"
Response (200)
{ "zip_url": "/download/raw/zip/", "count": 256, "files": [ { "name": "psa/Employment_Rate.csv", "url": "/download/raw/file/psa/Employment_Rate.csv" } ] }
GET /download/{kind}/zip/ Download all files as a ZIP archive
Example — download raw ZIP
curl -O "http://localhost:8000/download/raw/zip/"
Example — download processed ZIP
curl -O "http://localhost:8000/download/processed/zip/"

Returns application/zip. File is named raw_files.zip or processed_files.zip.

GET /download/{kind}/file/{filepath} Download a single file
Path parameters
ParameterTypeDescription
kindraw | processedData folder
filepathstringRelative path returned by the list endpoint
Example
curl -O "http://localhost:8000/download/raw/file/psa/Employment_Rate.csv"

Error Responses

All errors return JSON with an "error" key describing the problem.

StatusMeaningExample body
400Bad request / invalid parameter{"error": "kind must be 'raw' or 'processed'"}
404Resource not found{"error": "Dataset 'XYZ' not found."}
503Database unavailable{"status": "unhealthy", "database": "disconnected"}
